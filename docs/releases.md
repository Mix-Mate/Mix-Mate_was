## v1.2.0 — 2026-09-16

초대 링크, 모집 현황, MVP 메달 배지와 명단 다운로드 사용성을 개선했습니다.

### New
- **초대 링크**: 초대 링크를 통해 참여 코드를 직접 입력하지 않고 그룹에 참여할 수 있습니다.
- **초대 재발급**: 참여 코드나 초대 링크가 유출되었거나 만료된 경우 새 초대를 재발급할 수 있습니다.
- **모집 현황**: 모집 화면에서 현재 모집 인원과 최근 참여자를 바로 확인할 수 있습니다.
- **MVP 메달 배지**: MVP 누적 횟수에 따라 프로필에 메달 배지가 표시됩니다.

### Changed
- **명단 다운로드**: 다운로드한 명단에서 학번, 성별, 조번호 정보를 함께 확인할 수 있도록 변경했습니다.
- **라운드별 명단 다운로드**: 조가 확정된 이후 참가자 목록에서 라운드별 명단을 다운로드할 수 있도록 변경했습니다.

### Fixed
- **그룹 참여 오류**: 모집이 마감되었거나 차단된 그룹에 잘못 진입되던 문제를 수정했습니다.
- **투표 현황 표시 오류**: 관리자가 수동으로 투표 처리한 참가자가 미투표 목록에 남아있던 문제를 수정했습니다.
- **소셜 계정 회원탈퇴**: 소셜 로그인 계정에서 회원탈퇴가 정상적으로 처리되지 않던 문제를 수정했습니다.

### Improved
- **마이페이지 정보 표시**: 마이페이지의 계정 정보가 최신 정보로 표시되도록 개선했습니다.
- **모집 화면 사용성**: 최근 참여자 목록이 최신 참여순으로 안정적으로 표시되도록 개선했습니다.

## v1.1.0 — 2026-09-14

소셜 로그인, 개인정보처리방침, 명단 다운로드와 모바일 사용성을 개선했습니다.

### New
- **카카오 로그인**: 카카오 계정으로 회원가입과 로그인을 진행할 수 있습니다.
- **구글 로그인**: 구글 계정으로 회원가입과 로그인을 진행할 수 있습니다.
- **패치노트 화면**: 메인 화면에서 MixMate의 업데이트 내용을 확인할 수 있습니다.
- **명단 다운로드**: 종료된 그룹의 참가자 명단과 조 명단을 Excel 파일로 다운로드할 수 있습니다.
- **사용자 이름 수정**: 마이페이지에서 사용자 이름을 직접 수정할 수 있습니다.
- **최근 입력 프로필 자동 입력**: 그룹 생성과 입장 시 최근에 입력한 프로필 정보가 자동으로 채워집니다.
- **프로필 학번 입력**: 그룹 생성, 그룹 입장, 내 프로필 수정, 참가자 추가 화면에서 학번을 입력할 수 있습니다.
- **개인정보처리방침**: 개인정보 수집 항목과 보유 기간 등을 확인할 수 있는 페이지를 추가하고, 마이페이지에서 바로 확인할 수 있도록 했습니다.

### Changed
- **그룹 정보 수정 화면**: 그룹 홈에서 별도 화면으로 이동해 그룹명과 설명을 수정할 수 있도록 변경했습니다.
- **그룹 삭제 확인 화면**: 그룹 삭제 전 확인 화면을 더 명확하게 볼 수 있도록 변경했습니다.

### Improved
- **입력 오류 안내**: 이름, 그룹명, 프로필 등을 입력할 때 잘못된 내용을 바로 확인할 수 있도록 안내를 개선했습니다.
- **탭 이동 표시**: 화면에서 탭을 바꿀 때 선택된 탭이 더 자연스럽게 표시되도록 개선했습니다.
- **밸런스 게임 화면**: 모바일에서 밸런스 게임 선택지가 눌리거나 잘리지 않도록 화면 구성을 개선했습니다.
- **글자 가독성**: 여러 화면의 글자 크기와 굵기를 정리해 내용을 더 읽기 쉽게 개선했습니다.

### Fixed
- **모바일 하단 팝업 표시 오류**: 모바일에서 하단에 열리는 팝업이 순간적으로 튀거나 잘못된 위치에 표시되던 문제를 수정했습니다.
- **구글 계정 선택 오류**: 구글 로그인 시 다른 계정을 선택해도 기존 계정으로 로그인이 시도되던 문제를 수정했습니다.

### Security
- **소셜 로그인 보안 검증**: 카카오 로그인 과정에서 비정상적인 접근과 위조 요청을 방지하는 검증을 강화했습니다.

## v1.0.0 — 2026-09-06

MixMate 첫 정식 출시입니다. 모임 생성부터 조 편성, 투표까지 핵심 기능을 제공합니다.

### New
- 이메일 회원가입·로그인, 비밀번호 재설정
- 그룹 생성·수정·삭제, 초대코드 기반 그룹 참가
- 참가자 프로필 등록·조회·수정, 참가자 추가/삭제
- 조건 기반 자동 조 편성(성별·MBTI·학년 균형)
- MVP 투표, 2차 참여 여부 투표
- 참가자 차단 및 차단 목록 관리
- 마이페이지 내 정보 조회, 이름 수정
